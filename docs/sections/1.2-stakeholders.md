# 1.2 Stakeholders Identification

Stakeholders are everyone with an interest in, or influence over, OutageNet. Each is related to a real user or actor of the system. The problems the users face are described in Section 1.1, so this section lists only who they are and what they expect.

## Stakeholder Table

| Stakeholder | Role | Expectations | Related system user |
|---|---|---|---|
| Residents | Primary users. File outage and security reports, receive alerts, pay invoices, book events, vote in elections, and ask the chatbot about past outages | Learn the scope and cause of an outage within minutes. Receive alerts only when their own block is affected. File a report with one tap. Pay maintenance fees and vote through the app | Resident mobile app user |
| Colony office staff | Primary users. Load the household register, review confirmed events, publish official updates, and manage billing, events, and elections | One panel to see every confirmed event and its report distribution. Publish an official cause and restoration estimate once, instead of answering repeated phone calls. A simple interface usable without technical training | Admin panel user |
| Colony committee | Oversees the colony and holds the elections | Transparent invoices and payment records. Elections with one vote per verified household and results published when voting closes. A record of outage frequency and duration per block | Admin panel user (election and reports) |
| Gate guard | Files security reports from the gate | Report a security incident quickly through the same one-tap flow. Flag an active threat so the office is paged immediately | Resident mobile app user (security reports) |
| Development team | Design, build, test, and document the system | A well-defined scope, a stable API contract between modules, and clear ownership of each module | Developers; maintainers of the admin panel and system |

## Stakeholder Classification

- **Primary (direct users):** residents, colony office staff, gate guard.
- **Secondary (benefit from system outputs):** colony committee.
- **Key (build and deliver the system):** development team.
